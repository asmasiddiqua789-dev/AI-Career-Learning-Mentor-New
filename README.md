# AI Career Learning Mentor

An AI-powered career guidance app built with Streamlit and Gemini AI.

## Features
- **Career Guidance**: Get personalized career advice
- **Resume Analyzer**: Analyze and improve your resume  
- **Learning Roadmap**: Generate step-by-step learning plans
- **AI Chatbot**: Ask career-related questions

## Tech Stack
- Python
- Streamlit
- Google Gemini API

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Add your `OPENROUTER_API_KEY` in '.env' file
3. Run: `streamlit run app.py`
